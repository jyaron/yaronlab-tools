# yaronlab.tools

**Live site: [yaronlab.tools](https://yaronlab.tools)**

Research tools from the Yaron lab.

## Flagship: benchsiDE

**[benchsiDE](https://www.benchside.org)** (benchside.org) is the lab's tool for
differential expression and cross-dataset analysis of bulk RNA-seq counts, with
no R and no install. It offers filtering, TMM normalization, limma moderated-t and
voom with covariates and factorial designs, gene-set and co-expression tests,
random-effects meta-analysis across datasets, and replication of a signature in
independent data including across species by homology. Source and validation:
[github.com/jyaron/benchsiDE](https://github.com/jyaron/benchsiDE).

benchsiDE is a separate project with its own domain and repository; it is
featured here but not part of this site's source.

## Utilities

Small, single-file tools hosted under yaronlab.tools. Each is one self-contained
HTML file with no dependencies, no accounts, and no ads.

| URL | Tool |
|---|---|
| [/construct](https://yaronlab.tools/construct/) | Plasmid construct builder: fusion tags, fluorescent proteins and self-labeling tags, linkers, codon optimization for mammalian or E. coli expression, Kozak and Shine-Dalgarno signals, restriction-site avoidance, auto-generated methods text with citations, GenBank export |
| [/dna](https://yaronlab.tools/dna/) | DNA sequence toolbox: cleanup, reverse complement, DNA to RNA, case conversion, line wrapping, position numbering |
| [/credit](https://yaronlab.tools/credit/) | CRediT author contribution statement generator: paste an author list, check roles in a grid, copy a journal-ready statement |

## Offline use

Because every utility is one dependency-free file, you can save any tool's
`index.html` (or download it from this repo) and it will keep working
locally, with no internet connection.
