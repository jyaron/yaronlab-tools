yaronlab.tools/abbrev

Abbreviation checker

Scan a manuscript for acronyms, check that each is defined at first use, flag undefined or unused ones, and build the abbreviations table.

1Manuscript text

Paste the manuscript. The tool finds acronyms (two or more capital letters, optionally with digits), detects where each is defined as "full term (ABC)", and flags problems: used but never defined, defined but never used, and defined only after first use.
