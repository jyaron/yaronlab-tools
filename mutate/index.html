yaronlab.tools/mutate

Site-directed mutagenesis primer designer

Design mutagenesis primers for substitutions, insertions, and deletions, with nearest-neighbor Tm, host-optimized codons, and a ready-to-paste order table and methods text.

1Template coding sequence

Paste the DNA coding sequence to mutagenize (ATG... in frame). FASTA headers and whitespace are ignored.

No sequence yet.

2Mutations

Add one or more changes. Substitution uses protein notation (for example S65T): wild-type residue, position, new residue. Insertion adds residues after a position; deletion removes a residue range.

3Primer options

For substitutions the new codon is chosen as the most frequent synonymous codon in the selected host. Overlapping primers raise the default Tm target automatically. Melting temperatures use the SantaLucia 1998 nearest-neighbor model with the primer in excess (the convention used by IDT, NEB, and Primer3); set the oligo concentration to match your Tm tool (IDT defaults to 250 nM, NEB protocols to 500 nM).
Part of yaronlab.tools. Shared sequence logic (genetic code, codon usage, nearest-neighbor Tm, degenerate codons) is bundled in the page. Check every primer and library design against your own records before ordering.
